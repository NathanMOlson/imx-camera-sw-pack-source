# i.MX Camera Software Pack

[![Board badge](https://img.shields.io/badge/Board-i.MX_95_19x19_EVK-blue)](https://www.nxp.com/products/i.MX95)

*i.MX Camera Software Pack* includes camera drivers, libraries, calibration files, Yocto recipes to enable customers to
use selected off the shelf camera modules out of the box while utilizing the i.MX 95 internal ISP (Image Signal
Processor).

For more information on how to use Camera Software Pack, please refer to
[i.MX Camera SW Pack (i.MX 95 19 mm x 19 mm EVK) App Note](https://www.nxp.com/docs/en/application-note/AN14853.pdf)

## i.MX Camera Software Pack - Source

This repository contains source files and patches required to build Yocto Project Image to enable camera modules utilizing ISP (Image Signal Processor) on i.MX 95 19x19 EVK.

Camera Modules currently enabled :

1. Sony IMX219
2. Sony IMX258
3. Sony IMX477
